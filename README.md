# Speculum

**Forensic intelligence.** Speculum reconstructs how an intrusion
happened — how they got in, what they took, and whether the hands on
the keyboard were human or AI — while keeping a live Health Score and
Threat Score side by side.

The system lives in [`forensic-intel/`](forensic-intel/README.md):
collectors, immutable hash-chained logs, a timeline that rewinds to
the first anomaly, analyzers, surgical repair, and a dashboard that
shows both scores moving together.

*Speculum* — Latin for *mirror*: it watches the system, and it shows
the intruder their own reflection.
